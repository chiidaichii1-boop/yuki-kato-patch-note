## Entry

> Fixed: humans no longer lie awake replaying every embarrassing thing they have said since 2009; sleep now starts on time.

## How it works

`main.py` (Python 3 standard library only) writes that single line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output`). No input,
no network, no randomness — the output is deterministic.
